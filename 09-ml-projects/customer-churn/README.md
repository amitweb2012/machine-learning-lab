# Customer Churn Prediction

Classification project focused on class imbalance, precision/recall trade-offs, threshold selection, and explainability.

## Workflow

1. Define churn target
2. Audit data quality and leakage risk
3. Explore churn drivers
4. Build preprocessing pipeline
5. Train baseline and tree/boosting models
6. Compare classification metrics
7. Tune the decision threshold
8. Explain important features
