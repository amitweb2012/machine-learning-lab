# Fraud Detection

Imbalanced classification project focused on leakage prevention, precision-recall analysis, and business-oriented error analysis.

## Workflow

1. Define fraud event and evaluation window
2. Check class imbalance
3. Prevent temporal and feature leakage
4. Build preprocessing and validation strategy
5. Train candidate classifiers
6. Evaluate precision, recall, F1 and PR-AUC
7. Analyze false positives and false negatives
