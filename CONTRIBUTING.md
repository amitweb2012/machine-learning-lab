# Contributing

## Development

1. Create a branch for your change.
2. Keep experiments focused and reproducible.
3. Add or update documentation for new topics.
4. Add tests when behavior or reusable code is introduced.
5. Run `pytest` before opening a pull request.

## Project standards

- Prefer clear, modular Python.
- Keep notebooks focused on exploration and explanation.
- Move reusable logic into `src/` modules when a project grows.
- Document datasets and assumptions.
- Never commit credentials or sensitive data.
