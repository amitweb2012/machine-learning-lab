# Algorithms Reference

## Regression

| Algorithm | Typical use |
|---|---|
| Linear Regression | Continuous target with approximately linear relationships |
| Ridge | Linear regression with L2 regularization |
| Lasso | Linear regression with L1 regularization |
| Random Forest Regressor | Non-linear tabular regression |
| Gradient Boosting | Strong general-purpose tabular regression |

## Classification

| Algorithm | Typical use |
|---|---|
| Logistic Regression | Interpretable binary/multiclass baseline |
| KNN | Local similarity based classification |
| Naive Bayes | Fast probabilistic baseline |
| Decision Tree | Rule-like interpretable models |
| Random Forest | Robust non-linear classification |
| SVM | Margin-based classification |

## Unsupervised Learning

| Algorithm | Typical use |
|---|---|
| K-Means | Cluster discovery |
| DBSCAN | Density-based clustering |
| Hierarchical Clustering | Nested cluster structure |
| PCA | Dimensionality reduction |

## Ensemble Learning

- Bagging
- Random Forest
- Gradient Boosting
- XGBoost
- LightGBM

Each algorithm should be evaluated in context rather than by a universal ranking.
